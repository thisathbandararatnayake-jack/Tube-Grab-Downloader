# Tube-Grab-Downloader
Tube Grab is a sleek Windows desktop app for downloading YouTube videos and Shorts. Built with Python, CustomTkinter, and yt-dlp, it features fast downloads, a modern UI, local SQLite history tracking, and a simple .exe installer. The perfect, lightweight tool for offline media saving!
